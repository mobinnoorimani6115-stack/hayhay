# گزارش تحویل فاز اول

تاریخ: ۲۷ آبان ۱۴۰۵ / ۱۸ نوامبر ۲۰۲۶، منطقه زمانی تهران.

## محیط و اجرا

- مسیر پروژه: `E:\codex`
- Node.js: `26.13.0`؛ npm: `11.20.0`
- Next.js: `16.4.6`؛ React: `19.3.1`؛ TypeScript: `5.9.3`
- Prisma و adapter/client: `7.10.1`؛ Tailwind: `4.3.5`
- نصب وابستگی‌ها با موفقیت انجام شد و npm هنگام نصب نهایی صفر آسیب‌پذیری گزارش کرد.
- ESLint شاخهٔ ۹ برای سازگاری peer dependencyهای افزونه‌های Next.js انتخاب شده است؛ npm برای آن پیام پایان پشتیبانی می‌دهد. ارتقا به شاخهٔ ۱۰ باید همراه با پشتیبانی افزونه‌ها انجام شود.
- PostgreSQL، Docker و Git در PATH پیدا نشدند. دیتابیس محلی ساخته یا اجرا نشده است.
- فایل خالی اولیهٔ `1` در تحویل نهایی وجود دارد.

## نتیجهٔ بررسی‌ها

| بررسی                     | نتیجه                                           |
| ------------------------- | ----------------------------------------------- |
| `npm.cmd run db:generate` | موفق؛ Prisma Client تولید شد                    |
| `npm.cmd run db:validate` | موفق؛ schema معتبر است                          |
| `npm.cmd run lint`        | موفق؛ بدون خطا یا هشدار ESLint                  |
| `npm.cmd run typecheck`   | موفق                                            |
| `npm.cmd test`            | ۶ تست موفق                                      |
| `npm.cmd run build`       | موفق؛ صفحات استاتیک و جزئیات محصولات ساخته شدند |
| `npm.cmd run test:e2e`    | ۹ تست موفق در Chrome                            |
| بررسی بصری                | تصاویر صفحه اصلی دسکتاپ و موبایل بازبینی شدند   |
| migration روی PostgreSQL  | اجرا نشده؛ نیازمند فراهم‌شدن دیتابیس            |

تست unit در sandbox ویندوز با خطای `uv_os_get_passwd` مواجه شد و با مجوز اجرا خارج از sandbox موفق بود. اجرای اول آزمون مرورگر در پایان فرایند سرور متوقف ماند؛ اجرای مجاز خارج از sandbox به طور کامل پایان یافت.

آزمون مرورگر، صفحه اصلی RTL و فونت محلی، دسته/قطر/موجودی، جستجوی ارقام فارسی و مرتب‌سازی، حداقل ۱۰ شاخه، حد موجودی، اتصال تکی، جمع مبلغ و ماندگاری سبد، جلوگیری از خرید ناموجود، ورود بدون درخواست POST، پنل خواندنی، منوی موبایل و صفحه ۴۰۴ را پوشش می‌دهد. کنترل عرض موبایل روی هفت مسیر در viewport `390×844` انجام شد. viewport دسکتاپ `1440×1000` است.

دو ایراد یافت‌شده در اولین اجرای مرورگر برطرف شدند: تغییر فیلتر با History API و URL هماهنگ شد؛ حداقل عرض پوستهٔ مدیریت برای اسکرول مستقل جدول محدود شد.

## موارد ساخته‌شده

- تنظیمات اجرایی: `package.json`، lockfile، TypeScript، Next.js، Tailwind/PostCSS، ESLint، Prettier، Playwright و gitignore.
- تنظیمات داده: `.env.example`، `compose.yaml`، `prisma.config.ts`، schema شامل ۲۱ مدل، دو migration و کلاینت تنبل سرور.
- رابط: پوسته فروشگاه و مدیریت، Header، Footer، Brand، ProductCard و تصاویر برداری PipeArt.
- قابلیت‌های نمونه: کاتالوگ و فیلتر، انتخاب مدل، سبد مرورگر، فرم ورود با Zod و React Hook Form، جداول مدیریت.
- مستندات: README، معماری و نقشه فاز دوم، این گزارش و تصاویر پیش‌نمایش.

فهرست مسیرهای صفحات و درخت معماری در [README](../README.md) ثبت شده است.

## مرز قابلیت‌ها و فاز دوم

داده‌های فروشگاه ساختگی هستند. سبد نمونه فقط در مرورگر است و ثبت سفارش ندارد. فرم ورود تنها اعتبارسنجی می‌کند؛ اطلاعات را ارسال یا ذخیره نمی‌کند. پنل عمومی و صرفاً خواندنی است و هنوز احراز هویت ندارد. پرداخت، پیامک، رسید، حساب مشتری، مقایسه، Excel، PDF و عملیات نوشتن مدیر پیاده‌سازی نشده‌اند. دامنه‌ای متصل نشده و انتشار انجام نشده است.

در دیتابیس، وضعیت‌های سفارش دومرحله‌ای، رزرو موجودی و انقضا، snapshot سفارش/آدرس، رسید خصوصی و AuditLog پیش‌بینی شده‌اند. سرویس‌های اجرایی و آزمون تراکنش آن‌ها به فاز دوم تعلق دارند.

گام بعدی آماده‌سازی PostgreSQL و بررسی migrationها، سپس احراز هویت و کنترل مجوز سمت سرور است. جزئیات ادامه در [سند معماری](architecture.md) آمده‌اند.
